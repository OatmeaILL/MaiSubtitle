# ============================================================================
# 下面两个包**不能**跟着上面一起装（2026-09-17 新用户实测踩出）：
#
# 1) faster-whisper==1.2.1   （识别引擎，必需）
#    它声明依赖 CPU 版 onnxruntime。按常规装法会把 CPU 版和我们钉的
#    onnxruntime-gpu==1.23.2 装进**同一个 site-packages**（两个 wheel 都提供同名的
#    onnxruntime 包），谁后装谁覆盖：GPU provider 失效，DLL 与 .pyd 版本还可能错配
#    （本项目本来就吃过原生崩溃的亏）。所以 --no-deps 装，再靠 onnxruntime-gpu
#    提供同名的 onnxruntime 模块 —— 它其余的依赖（ctranslate2 / huggingface-hub /
#    tokenizers / av / tqdm）上面都已显式列出。
#
# 2) funasr-onnx==0.4.3      （可选：中文补标点走 CPU 小模型 / FSMN VAD）
#    它声明 numpy<=1.26.4，与本项目的 numpy==2.5.3 **解析无解**（这个上限是上游过时的
#    元数据，实测 0.4.3 配 numpy 2.x 正常工作）。它也声明 onnxruntime，理由同上。
#    它的依赖里只有 jieba 是上面没有的，一并补。
#
# 正确装法（scripts/setup_first_run.py 里自动做，也就是安装器的"[2/5] 单独装"那步）：
#   .venv\Scripts\python.exe -m pip install --no-deps -i https://mirrors.aliyun.com/pypi/simple/ faster-whisper==1.2.1
#   .venv\Scripts\python.exe -m pip install --no-deps -i https://mirrors.aliyun.com/pypi/simple/ funasr-onnx==0.4.3 jieba
# （用 uv 建的环境没有 pip，把上面两条的 ".venv\Scripts\python.exe -m pip install" 换成
#   "uv pip install --python .venv\Scripts\python.exe"，并把 -i 写成 --index-url）
